# Power Automate voor beginners

Power Automate is Microsoft's no-code automatiseringstool. Je kunt ermee e-mails versturen, goedkeuringen starten en lijsten bijwerken — zonder een regel code.

## Wat is een flow?

Een flow bestaat uit een **trigger** (wat start de flow?) en een of meer **acties** (wat doet de flow dan?).

## Je eerste flow

1. Ga naar flow.microsoft.com
2. Kies **+ Nieuw** → **Geautomatiseerde cloudflow**
3. Kies een trigger, bijvoorbeeld "Wanneer een e-mail binnenkomt"
4. Voeg een actie toe
